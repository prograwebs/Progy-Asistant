## 7. Corrección del error PGRST303 después del login

Problema observado:

```text
PGRST303
Tu sesión terminó. Vuelve a iniciar sesión.
```

El usuario tenía que recargar manualmente `/panel`.

Cambios realizados:

- Creado [postgrest-retry.ts](/mnt/hdd/Proyectos/fullstack/Progy-Asistant/lib/http/postgrest-retry.ts).
- Solo `401 + PGRST303` se reintenta.
- Se espera:
  - 400 ms antes del primer reintento;
  - 1.000 ms antes del segundo.
- Se hacen como máximo tres intentos totales.
- Se reutiliza el mismo correlation ID.
- Los fallos temporales no se registran; solo se registra el fallo definitivo.
- Otros errores JWT no se reintentan.
- Todos los 401 de la capa de datos utilizan el código público:

```json
{
  "error": "Tu sesión terminó. Vuelve a iniciar sesión.",
  "code": "session_refresh_required"
}
```

En el cliente:

- `useWorkspace` dejó de buscar textos como `jwt`, `token` o `session`.
- Solo reacciona a `401 + session_refresh_required`.
- Ejecuta `/api/auth/refresh` una sola vez.
- Repite workspace una sola vez.
- Si vuelve a fallar, redirige al acceso.
- No existe un bucle infinito de refresh.
- No se muestra la alerta mientras la recuperación automática está en curso.

Después de login o registro con sesión inmediata se utiliza:

```ts
window.location.replace("/panel");
```

Esto fuerza una nueva navegación con las cookies recién almacenadas.

## 8. Límite global de payload

Creado [limits.ts](/mnt/hdd/Proyectos/fullstack/Progy-Asistant/lib/config/limits.ts).

Nueva variable para los limites de subida de archivos antes estaba fijo en 8 y 12 MB como vercel limita a 4 MB:

```env
NEXT_PUBLIC_PROGY_MAX_PAYLOAD_MB=4
```

Exporta:

- `MAX_PAYLOAD_MB`;
- `MAX_PAYLOAD_BYTES`;
- `MAX_BASE64_SOURCE_BYTES`;
- validaciones para archivos y respuestas binarias.

Comportamiento:

- El valor predeterminado es 4 MB.
- Valores inválidos, cero o fuera del rango permitido vuelven a 4 MB.
- Se aceptan decimales.
- Cambiar la variable en Vercel requiere un nuevo build/deployment.
- Se dejó margen frente al límite de 4,5 MB de Vercel Functions.

El límite se aplica a:

- grabaciones antes de enviarlas desde el navegador;
- audio recibido por `/api/assistant/turn`;
- audio generado que se devolverá como base64;
- previews binarias de ElevenLabs;
- documentos de importación;
- selección de archivos desde la interfaz;
- texto visible “máximo X MB”.

Los límites anteriores de 8 MB y 12 MB fueron eliminados.

Los excesos devuelven HTTP 413 con un mensaje público que indica el límite configurado.
